# Baek-il — short story

The project's initial pitch and the **vertical slice** of the Ddakji
universe: it tests the world, the voice, and this entire pipeline
(draft → coverage → revision → lock → export → publish) before the epic
commits (DR-0006). Two scenes: a main narrative and a shorter flashback.

**Status:** scaffolded; scenes at `sketch`; nothing drafted yet.

| File/folder | Role |
|---|---|

| `style.md` | this work's voice, register, tense, POV style |
| `outline.md` | wireframe: scene order and assembly (order lives HERE, not in filenames) |
| `scenes/` | scene specs — the planning layer (collaborative) |
| `drafts/` | prose — **human-only**; start a draft by copying `templates/draft.md` |
| `editorial/` | coverage reports and suggested fixes (applied by hand) |
| `archive/` | frozen drafts per release (generated by `/release`) |
| `publish/` | export-ready output (generated by `/publish`) |
| `ROADMAP.md` / `CHANGELOG.md` / `backlog.md` | plan / shipped / open questions |
