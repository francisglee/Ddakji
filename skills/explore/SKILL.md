# /explore — thesis work

Governed by `process/roles/researcher.md` and the dramaturg ethic
(`process/roles/dramaturg.md`): the AI researches, connects, and
challenges; conclusions about meaning are the author's. Lifecycle:
`process/workflows/canon-lifecycle.toml`.

1. Start from `templates/exploration.md` in `research/explorations/`:
   `explores:` (entity type), `date-created:`, backlog anchor in
   `informs:` if one exists.
2. Map **Dimensions** — the axes of the question — before arguing
   anything.
3. Develop **Theses**: multiple positions per dimension, each argued
   seriously, including ones the author seems unlikely to choose.
   Never converge for the author; never rank the theses unasked.
4. Ground where possible: cite `sources:`; claims worth verifying spin
   off as `/research` notes; questions → `research/backlog/`.
5. The author's provisional leanings live in Notes, freely revised.
6. **Distillation happens only on the author's initiative**: they
   choose champions; the world entity is created citing this doc;
   backfill `informs:` here. Rejected theses stay — cited, never
   copied.
7. Remind at distillation: the canonization DR's Alternatives must
   engage the unchampioned theses (DR-0010).
