# /interview — testimony under consent

Governed by `process/roles/researcher.md` (axioms 2, 3: testimony and
consent). The interview itself is conducted by the author; this skill
prepares and processes.

## Prep

1. Check `research/README.md` coverage targets and open
   `research/backlog/` items for what this interview should seek.
2. Draft question areas (open-ended, experience-first); note consent
   items to raise: recording, quotability, anonymization.

## Process

1. **Consent block first.** Create the doc from
   `templates/interview.md`; complete `consent:` (recorded / quotable /
   anonymize) before anything else is written. When in doubt, the
   answer is no.
2. Fill identity fields per consent (anonymize if requested), `date:`
   (interview), `date-created:` (today), `language:` — flag translated
   quotes.
3. Summary and Notable moments per consent terms; transcript if
   recorded and sized for the repo (raw recordings beyond a few MB stay
   outside, linked).
4. Treat testimony as testimony: claims it yields enter notes as
   `unverified` until corroborated; never copy interview material
   toward `publish/` — the publish checklist enforces `quotable`.
5. Cross-link `informs:` (world slugs, backlog IDs); set `status:`
   (raw → summarized → integrated as its facts flow onward).
6. Follow-ups → the doc's Follow-ups section AND `research/backlog/`
   entries.
